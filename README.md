# Pixel Studio — 個人用ドット絵制作アプリ

React + TypeScript + Vite で作った、PC・スマホ対応のドット絵エディタです。

## すぐに使う（PC）

Node.js 20.19+ または 22.12+ を用意してください。

```bash
npm install
npm run dev
```

表示された `http://localhost:5173` をブラウザで開きます。Firebaseを設定しなくてもブラウザ内の作品保存は利用できます。

## 主な機能

- ドット単位のペン・消しゴム・塗りつぶし・スポイト・線・四角・塗り四角・楕円
- 左右・上下対称、グリッド、ズーム、キャンバスサイズ変更、反転・90°回転
- 矩形範囲選択・コピー・貼り付け・ドラッグや矢印ボタンによる移動・選択範囲の左右反転
- 標準256色パレット・色パレット編集・PNG画像からパレット読み込み（最大256色）・パレットの別名保存と切り替え・色の一括置換、PNGインポート
- アニメーションの追加、フレーム追加・複製・リンク複製・削除・順序変更・FPS・表示時間・再生モード・オニオンスキン
- PNG / GIF / スプライトシート / JSON書き出し、Pyxelパレット（.pyxpal）書き出し、Pyxel 16色変換、透過色選択
- IndexedDBへの手動保存、別名保存、作品一覧・フォルダ・検索・並び替え・名前変更・複製・完全削除
- 「作品一覧」から許可済みのGoogleアカウントでログインすると、保存した作品をPC・スマホで同期
- 名前付きパレットはGoogleログイン後に自動同期。同じアカウントのスマホ・PCから切り替えて使えます。
- スマホではキャンバスを中心に表示し、ツール・パレット・コマ操作は下部バーから開閉します。

## Firebase設定（クラウドを使う場合）

1. Firebase Console で自分用プロジェクトを作成します。
2. **Authentication** で「Google」を有効にし、承認済みドメインに公開先ドメインを登録します。
3. **Cloud Firestore** データベースを作成します。
4. プロジェクト設定の「ウェブアプリを追加」で Firebase 設定値を確認します。
5. `.env.example` を `.env` にコピーして各値を入力します。`VITE_ALLOWED_EMAIL` には自分のGoogleアカウントのメールアドレスを設定します。
6. `firestore.rules` の `isOwner` に指定するメールアドレスを `VITE_ALLOWED_EMAIL` と合わせます。ユーザーIDと確認済みメールの両方でアクセスを制限します。
7. `npm install -g firebase-tools` → `firebase login` → `firebase use --add` → `npm run build` → `firebase deploy --only hosting` で公開します。ルールは Firebase Console で別途公開するか `firebase deploy --only firestore:rules` で適用してください。

**重要：** `.env` に記載したメールアドレスだけでなく、Firestoreルールも必ず制限してください。フロントエンドのログイン制限だけではデータ保護になりません。Firebase設定値はクライアントに含まれますが、パスワードや秘密鍵は置かないでください。

## 保存の仕組み

- 「作品一覧」から許可済みのGoogleアカウントでログインします。初回のGoogleログインでアカウントが作成されます。
- 「保存」を押すとIndexedDBへ保存します。ログイン中はクラウドにも送信します。ログイン前に保存した作品も、同期待ちのものはログイン後に送信します。
- 他の端末では同じGoogleアカウントでログインし、「作品一覧」を開くと作品を自動で取得します。「同期する」でも最新の状態を取得できます。
- オフラインでは同期待ちとして記録し、再接続したときに再送します。**描画の自動保存はありません**。
- 異なる端末から競合する保存が検出された場合、端末側のコピーを別作品として残し、クラウド側の作品も保持します。どちらを残すかは作品一覧で確認してください。
- 削除は確認後に完全削除し、オンラインであればクラウドにも反映します。
- 保存履歴の永続保存は未実装です。Undo/Redoは編集中のみ最大100操作です。
- ブラウザのサイトデータ削除でローカル作品が消える場合があります。JSONを別途保存してください。
- パレットは名前を付けて「別名で保存」し、「保存したパレットを使う」から切り替えられます。色の編集・PNG読み込みでは名前付きパレットを上書きしません。編集中の色は端末内に保持され、次回起動・新規作品へ引き継がれます。
- パレット欄の「Googleでログインして同期」を押すと、保存済みパレットをFirestoreの `users/{uid}/palettes/{id}` に自動保存します。同じGoogleアカウントの別端末では一覧を自動で受信します。オフラインで保存した名前付きパレットも、再接続後に送信します。
- クラウドからの受信は一覧への追加だけを行い、編集中の絵や選択中の色は切り替えません。同名の別色・旧形式のID衝突も、両方のパレットを残します。
- ファイルによるバックアップも利用できます。パレット欄の「ファイルでバックアップ」からJSONを書き出して読み込めます。

## 使用色をPyxelへ書き出す

「作品一覧」の各作品にある「Pyxelパレット」を押すと、すべてのアニメーションとコマで実際に描かれた色を `.pyxpal` に保存します。色は初めて出現した順に、重複と透明部分を除いて最大256色を書き出します。編集中の作品からは「書き出し」でも作成できます。

Pyxel Editorで使うには、たとえば `game.pyxres` と同じフォルダに `game.pyxpal` として置き、リソースを開きます。Pythonからは `pyxel.init(...)` のあとに `pyxel.load_pal("game.pyxpal")` を呼びます。行順が色番号になるので、新しい絵をPyxelへ取り込む前にパレットを適用してください。[Pyxel公式FAQ](https://github.com/kitao/pyxel/blob/main/docs/faq-ja.md)

## 現時点での制限（仕様との差分）

この版は**初期実装**です。以下は今後の拡張が必要です。

- なげなわ選択、選択範囲の90°回転・拡大縮小
- スマホの指先オフセット・タップ確定モード、フローティングツールの位置カスタマイズ、ピンチズーム
- 競合時の**並列比較画面**（現在は両版を別作品として保持し、作品一覧で個別に開く方式）
- アニメーションプレビューの独立再生ウィンドウ、アニメーションのリンクコピーの完全な相互更新
- スプライトシートの書き出しプレビューと変更色の一覧表示
- 保存容量の詳細監視（現在は作品が約500KBを超えた際の警告のみ）
- Firestore 1MiBを超える大きな作品の分割保存

このアプリは個人用の試作であり、Firebaseプロジェクトの設定、権限ルールの公開、実端末での検証を終えるまでは本番運用しないでください。
